# Domain Glossary — Dukaan Dost

> Maintained by requirements-analyst agent. All agents use these terms consistently.

| Term | Definition |
|------|-----------|
| Udhaar | Informal credit extended to a customer — the core concept the app digitizes |
| Baaki | Outstanding balance owed by a customer |
| Hisaab | Account / financial calculation |
| Hisaab saaf | "Account clear" — balance is exactly zero |
| Kiryana store / Dukaan | Corner grocery store (the primary user's business) |
| Dukaan dar | Shop owner — the primary user persona |
| Grahak | Customer — the secondary/passive persona who receives WhatsApp messages |
| Takaza | Collection reminder sent to a customer |
| Wapsi | Payment returned / received from a customer |
| DSR | Distributor Sales Representative — field salesperson running a beat route |
| Beat | Fixed weekly/bi-weekly route a DSR follows to visit retailer accounts |
| Event log | The append-only, immutable record of all transactions — the source of truth |
| Paisa | Monetary unit — amounts stored as integer paisa (PKR × 100) |
| Iron Rules | The non-negotiable architectural constraints in CLAUDE.md |
| Story | A single unit of implementable work, defined in docs/stories/ |
| Human Gate | A point in the workflow requiring explicit human approval before proceeding |
| Offline-first | Architecture where local write always succeeds before network involvement |

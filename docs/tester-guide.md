# Dukaan Dost — Tester Installation Guide

Welcome! This guide will help you install the Dukaan Dost app on your Android phone.
It takes about 5 minutes.

---

## Step 1 — Download the APK

You will receive the APK file in one of these ways:

**Via WhatsApp:**
- Tap the attachment → tap the download icon → tap **Open**

**Via Google Drive link:**
- Open the link in Chrome → tap the download icon (⬇) at the top right
- Find the file in your Downloads folder

**Via GitHub:**
- Visit the link provided → tap **app-release.apk** → tap **Download**

---

## Step 2 — Allow installation from unknown sources

Android blocks apps not from the Play Store by default. You need to allow it once.

Find your Android version: **Settings → About phone → Android version**

### Android 8 or 9
1. Go to **Settings → Security**
2. Scroll down to **Unknown sources**
3. Toggle it **ON**
4. Tap **OK** on the warning

### Android 10 or 11
1. Open your **Files** app (or Chrome, whichever you used to download)
2. Go to **Settings → Apps → Special app access → Install unknown apps**
3. Tap **Files** (or **Chrome**)
4. Toggle **Allow from this source** to **ON**

### Android 12 or 13 or 14
1. Go to **Settings → Apps**
2. Tap the three-dot menu (⋮) → **Special app access**
3. Tap **Install unknown apps**
4. Tap **Files** (or **Chrome**)
5. Toggle **Allow from this source** to **ON**

> **Roman Urdu:** Android aap ko Play Store ke bahar se apps install karne se rokta hai. Upar diye gaye steps follow karein aur "Allow" ya "ON" karein.

---

## Step 3 — Install the app

1. Open your **Files** app
2. Go to **Downloads**
3. Tap **app-release.apk** (or **app-debug.apk**)
4. Tap **Install**
5. If you see "Play Protect" warning, tap **Install anyway**
6. Tap **Open** when installation is complete

---

## Step 4 — Register and log in

1. **Enter your mobile number** in the format **03XX-XXXXXXX** (Pakistani number)
   > **Roman Urdu:** Apna Pakistani mobile number likhein, jaise: 0300-1234567

2. Tap **OTP بھیجیں** (Send OTP)

3. **Wait for the SMS** — you will receive a 6-digit code
   > **Roman Urdu:** Aapke phone par ek 6 number ka code SMS se aayega

4. Enter the 6-digit code on the next screen

5. **Enter your shop name** on the setup screen
   > **Roman Urdu:** Apni dukan ka naam likhein, jaise: "Kareem General Store"

6. Tap **محفوظ کریں** (Save) — you are now in the app ✅

## Troubleshooting

| Problem | Solution |
|---|---|
| OTP SMS did not arrive | Contact the developer — SMS delivery depends on the backend setup |
| App crashes on open | Make sure you have Android 10 or higher |
| "App not installed" error | Make sure you completed Step 2 (unknown sources) |
| Cannot connect to server | Make sure you have mobile data or Wi-Fi. If the problem persists, contact the developer |
| Screen is blank / loading forever | Close the app completely and reopen it |
